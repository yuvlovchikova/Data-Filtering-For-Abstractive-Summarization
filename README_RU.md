# Фильтрация данных для абстрактивной суммаризации

Учебно-исследовательский проект НИУ ВШЭ (2022) о том, как фильтрация обучающих данных влияет на качество абстрактивной суммаризации.

Проект построен в data-centric парадигме: вместо изменения только архитектуры модели исследуется, может ли отбор обучающих примеров улучшить итоговое качество суммаризации.

## Стек

Python · PyTorch · Hugging Face Transformers · Hugging Face Datasets · BART · ROUGE · Jupyter

## Эксперимент

Ноутбук использует датасет XSum и дообучает `facebook/bart-base`. Пайплайн включает:

1. загрузку и предобработку XSum;
2. токенизацию для sequence-to-sequence обучения;
3. дообучение BART с помощью `Seq2SeqTrainer`;
4. анализ функции потерь по отдельным примерам и фильтрацию выбросов в обучающей выборке;
5. повторное обучение на отфильтрованном подмножестве;
6. оценку по ROUGE-1, ROUGE-2, ROUGE-L и ROUGE-Lsum.

## Репозиторий

- `filtering_for_abs_summarization.ipynb` — полный исследовательский ноутбук: подготовка данных, baseline-обучение, фильтрация, повторное обучение и оценка.

## Контекст

Это учебно-исследовательский экспериментальный репозиторий. Ноутбук сохраняет исходный исследовательский процесс и результаты и предназначен для демонстрации эксперимента, а не как production-сервис суммаризации.
